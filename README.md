# redtigra_learning

Study tools and notes / Учебные материалы и инструменты.

## NCA-AIIO glossary / Глоссарий NCA-AIIO

[`nca-aiio-glossary/index.html`](nca-aiio-glossary/index.html)

**EN:** A single-file, offline-friendly flashcard app for the NVIDIA *AI Infrastructure and Operations Fundamentals* (NCA-AIIO) exam. 161 cards in 7 sections (Compute, Products, Networking, Storage, Infrastructure, Software, Models). Bilingual RU/EN toggle, fuzzy search, alphabetical index, random card, keyboard shortcuts, progress saved in the browser (localStorage). No build step, no dependencies: open the file in a browser or serve it with GitHub Pages.

**RU:** Одностраничное приложение с карточками для подготовки к экзамену NVIDIA NCA-AIIO. 161 карточка в 7 разделах, переключатель RU/EN, нечёткий поиск, алфавитный указатель, случайная карта, горячие клавиши, прогресс сохраняется в браузере. Без сборки и зависимостей: откройте файл в браузере или подключите GitHub Pages.

Keys / Клавиши: `Space` flip, `←/→` navigate, `K` known, `R` random, `Enter` search, `Esc` close.

> Unofficial study aid, not affiliated with NVIDIA. / Неофициальный учебный материал, не связан с NVIDIA.
